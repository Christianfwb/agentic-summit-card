Abstract

CARA-UTM is a proposal for a computational model that works through resonance rather than gates. Its core is simple to state: inputs are encoded as frequencies. Couplings between the oscillating units determine the operation — the coupling is the program. The coupled ensemble evolves on its own, and the result is read out as the phase relationships between the units. Whether this model offers a measurable advantage over gate-based control on real hardware remains open; the test is defined in Section 7.

[Computational model: ONTOLOGY · Advantage: HYPOTHESIS]

The foundation is the Frequency Law (2025): frequency is taken as primary, time as phase progression, and mass as stabilized frequency. The relationship between phase, frequency and duration is implemented and tested; the causal direction is an interpretation. CARA uses the word Nullraum — rendered here as “Null Space” — as a working term for the state before any decision. It is a framework-specific term, distinguished from established concepts in Section 2.

[RELATION · Causal direction: ONTOLOGY]

A selected application is a Governor that evaluates AI responses before release using a resonance heuristic. It runs on classical hardware. This document describes the approach, the publicly disclosed state of development, and the open tests. Further architectural and implementation details are outside the scope of this publication. 1. Starting point

A quantum computer computes by applying gates: discrete interventions that rotate, entangle and flip the state, aligned to a global clock. Each intervention is a source of error, and the errors accumulate. A Fourier transform on ten qubits requires approximately fifty-five operations in the usual gate decomposition; the number grows quadratically with the number of qubits.

[RELATION]

The industry’s response is error correction: more qubits, more gates, deeper cooling. This is the state of the art, and there are good reasons for it. This document asks a different question: how much of the control overhead arises from the substrate, and how much from the control logic imposed on it?

[RELATION · Question: open]

Our working hypothesis: some decoherence is a synchronization error rather than environmental noise. An inherently oscillating system is forced into a linear time grid. If this is correct, control oriented to the phase of the units rather than a global clock should maintain coherence measurably longer. If it is not, the test in Section 7 will show no difference.

[HYPOTHESIS]

1.1 A proposed analogy. A language model generates responses token by token, each chosen according to probability from a state that contains many possible continuations at once. The symptom when this goes wrong is called hallucination. We see a structural similarity to decoherence: in both cases, a state that superposes possibilities is externally forced into a sequence of discrete steps, and the control process does not see the structure of the state from which it selects. Whether this similarity has a common cause is not established — similarity does not imply one. It is the reason CARA’s first application is a language model: there, the resonance heuristic can be tried on any computer, long before quantum hardware enters the picture.

2. The Null Space — a framework-specific term

CARA uses the word Nullraum (“Null Space”) for the state before any decision. It refers to Hilbert space at the moment when a state holds all possibilities simultaneously, before one becomes actual. The name stands for “nothing distinguished yet,” not “nothing present.” It is a working term of the framework, not an established technical term, and is deliberately distinguished from identically named or neighboring concepts.

4. The resonance program

At CARA’s core is a computational model in which frequencies, coupling and interference perform the operations rather than gates. “Without gates” means precisely this: without a predefined sequence of discrete quantum gates. The model replaces the sequence with continuous evolution under designed couplings.

4.1 How computation works. A gate is an instruction: rotate this state by this angle now. The resonance program issues no instructions; it establishes conditions and lets the system run. Four steps. Encoding: the input is set as a collection of frequencies — each unit, which we call a Phase-Token, receives an initial frequency and phase. Operation: the computational rule lies in the coupling — who oscillates with whom, and how strongly. The coupling is the program. Execution: the coupled ensemble evolves on its own; phases converge or diverge, and the result emerges as an interference pattern that stabilizes. Readout: the relative phases of the tokens are measured. The image is that of coupled pendulums. None is pushed individually. Their lengths and connections are set, they are released, and the pattern they settle into is the answer.

[Computational model · ONTOLOGY]

4.2 The roles of the three quantities. Frequencies carry the input and each unit’s local time base. Couplings carry the operation; a different coupling structure is a different program. Interference performs the computation: it reinforces phase configurations that match the coupling and cancels the others. The compiler that translates a logical requirement into a coupling structure is the Translation Matrix.

[ONTOLOGY]

4.3 Phase-Tokens and local time. Each unit is intended to derive its time from its own phase and frequency rather than being tied to a global clock. The expectation is that an ensemble keeping its members in phase will damp deviations of individual units — we call this Resonance Lock. If that happens, some error correction would shift from an active computational workload to a passive property of the ensemble. Whether it happens, and whether shielding can thereby be reduced, has not been demonstrated.

[HYPOTHESIS]

4.4 Context. The model is related to analog quantum computing and Hamiltonian simulation, which also use continuous evolution rather than gate sequences. The difference lies in the treatment of time: there, evolution runs against a global clock; here, against each unit’s local phase. Whether this difference is measurable is addressed by Section 7.

5. Selected application: the Governor

As an application, this document presents a Governor that evaluates AI responses. Two intervention points must be distinguished. Before release: the generated response is checked before it reaches the user or the next action. This is the Governor, and it is running. Before token generation: an intervention in the state itself, before a token emerges. This is the goal of the Translation Matrix and remains a hypothesis. In both cases, the model itself is left unchanged; the Governor sits in front of it like a measuring instrument.

[Before release: RUNNING (internal) · Before token generation: HYPOTHESIS]

[RUNNING (internal) · Thresholds internally calibrated]

Stage 2 — Emptiness. The Governor uses a defined reference point for “nothing said.” A response close to it has the grammar of meaning without the substance: semantic pseudo-coherence. The internal system name for this is Habuubuu.

[RUNNING (internal) · Thresholds not externally calibrated]

Stage 3 — Resonance. The Flash Score is a heuristic. It measures how strongly a response vector resonates with the framework’s reference frame. It does not measure factual accuracy, and it is not the same as coherence in the logical sense. A response can resonate strongly and be false. The score is a signal that complements other checks, not a judgment of truth.

[RUNNING (internal) · Heuristic]

Stage 4 — Boundary. Many existing safety mechanisms work through lists and trained refusals; these are effective and have their place. LexLuxDies complements them with a single principle: ∞ − 1 = you. No finite system may claim the position of the infinite. A model that outputs “I am the universe” is stopped and reset, regardless of whether the sentence appears on a list. In the current version, detection is keyword-based.

A single positive run is not a finding. An advantage counts as a result only when it is reproducible and statistically robust. Each test examines one hypothesis under defined conditions. A negative result falsifies that hypothesis under those conditions — not automatically the entire approach; a positive result does not confirm the approach as a whole.

8. Why this matters for agent systems

Autonomous agents complete transactions, call other agents and execute contracts. Today, it is usually the output that is checked after it has been generated — often by another model with the same blind spot. The Governor intervenes at the same point, but uses a different metric: resonance against a defined framework rather than probability. Release or stop, before the action enters the chain.

The Governor is not an operator-managed prohibition list, but an evaluation geometry with a disclosed principle. For architectures intended to operate without a central authority, this is a difference worth discussing.

9. Limitations

Not yet available: a run on a quantum chip; an external evaluation of the Governor; evidence that the resonance program’s overall resource balance is more favorable than gate-based control; evidence for the analogy between hallucination and decoherence. These are the open points, and they are marked as such in the document.

The concept catalog prescribes what also applies here: internal consistency is not empirical proof. An algebraic rearrangement does not establish a causal direction. A document that fails to state its own limits exhibits precisely the hubris that LexLuxDies is intended to prevent.
